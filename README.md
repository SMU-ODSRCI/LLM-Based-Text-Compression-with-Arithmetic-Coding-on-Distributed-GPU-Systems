# LLM-based-Hybrid-Text-Compressors-on-HPC
This work presents the first comparative scalability analysis of hybrid compressors that combine transformer-based Large Language Models (LLMs), such as BERT, RoBERTa, T5-small, and Llama-3.2-3B with Arithmetic Coding (AC) on a State-of-the-Art (SOTA) High Performance Computing (HPC) platform.
