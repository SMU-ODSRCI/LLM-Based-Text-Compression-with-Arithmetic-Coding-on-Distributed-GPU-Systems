# LLM-based-Hybrid-Text-Compressors-on-HPC
This work presents the first comparative scalability analysis of a data compression technique that combines transformer-based Large Language Models (LLMs), such as BERT, RoBERTa, T5-small, and Llama-3.2-3B with Arithmetic Coding (AC) on a State-of-the-Art (SOTA) High Performance Computing (HPC) platform. This study also highlights the architecture-driven trade-offs in performance and compression efficiency of these hybrid compressors. Artificial Intelligence (AI)/Machine Learning (ML)-based data compression has broad relevance, but HPC provides us with a unique opportunity to stress-test such techniques in extreme settings. Moreover, the proliferation of digital data has emphasized the importance of efficient compression to reduce storage and transmission costs. Therefore, we also investigate the performance metrics of the aforementioned hybrid frameworks at HPC scale.
